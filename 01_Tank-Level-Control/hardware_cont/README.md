# Tank Level Control

## Project Overview

PLC-based tank level control project developed using Siemens TIA Portal.

## Software

- Siemens TIA Portal
- WinCC

## Main Functions

- Tank level monitoring
- Pump control
- Manual/automatic operation
- HMI visualization

## PLC Programming

The project uses Ladder Logic for PLC programming.

Main instructions:

- MOVE
- NORM_X
- SCALE_X
- TON
- TOF
- SR/RS

## HMI

The HMI displays:

- Tank level
- Pump status
- Operating mode
- System status
