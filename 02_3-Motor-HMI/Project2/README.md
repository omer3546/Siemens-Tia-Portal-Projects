# Motor Control – Siemens TIA Portal

## Project Overview

This project is a PLC-based motor control application developed using Siemens TIA Portal.

The project focuses on controlling motors through a PLC and monitoring and managing the system via an HMI.

## Technologies Used

- Siemens TIA Portal
- Siemens PLC
- WinCC HMI
- Ladder Logic

## Project Functions

- PLC-based motor control
- Manual / automatic operating modes
- Motor status monitoring
- Displaying motor status and fault information on the HMI
- Motor control via HMI

## PLC Programming

The PLC control program was developed using Ladder Logic.

Main PLC functions used in the project:

- FB (Function Block)
- DB (Data Block)
- MOVE
- TON / TOF / TP
- SR / RS
- Manual / automatic control logic

## HMI

An operator interface was developed using WinCC.

The HMI provides:

- Motor status monitoring
- Manual / automatic mode selection
- Motor control
- Status and fault information
